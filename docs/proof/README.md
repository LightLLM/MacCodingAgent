# macOS proof artifacts

Generated by:

```bash
npm run test:macos:unit
npm run test:macos:e2e
```

On GitHub Actions, the **macOS desktop e2e (real macOS)** job runs `macos-e2e.sh` on `macos-latest` and uploads:

- `macos-package-validation.json`
- `macos-e2e-health.json`
- `macos-e2e-chat.json`
- `macos-e2e-report.json`
- `macos-electron-health.json` / screenshot when Electron launches on Darwin
